# Benny

Benny is the dormant issue-triage and reproduction automation pack adapted from pstack. It is not an active schedule or a set of top-level slash skills.

Point the agent at [FOR_AGENTS.md](FOR_AGENTS.md) and name the target project. Setup copies the pack into a task-owned project directory, verifies the shared Hapstack skills, and prepares explicit triage and reproduction configuration. Connected Slack/tracker controls and a supported scheduler are prerequisites for the selected tasks.

The host-neutral [setup instructions](skills/setup-benny/SKILL.md) govern creation and updates. No private routine editor or Cursor plugin settings file is required. Schedules, posting permissions, repositories, service identities, and secret handling must be explicitly configured before activation.
