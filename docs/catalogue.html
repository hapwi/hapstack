What came from pstack?

All 53 top-level skills, 24 principles, 23 playbooks, the guide, helper scripts, and dormant Benny pack were adapted from pstack 0.15.23.

Three skills were renamed: poteto-mode → hap-mode; poteto-help → hap-help; setup-pstack → setup-hapstack.

Five skills were added: patcher, ship, deslop, control-ui, control-cli. Deslop came from Cursor's team kit; the control adapters use the current host's available tools.

Installation guide
Setup & runtime defaults

Setup saves model-role, reasoning-effort, delegation, tooling, and shipping preferences. Global applies across your projects; project settings override global settings for one repository.

Setup is optional. Without it: use the current model, delegate when requested, preserve project tooling, and follow project versioning. It does not install tools, change the active chat model, activate jobs, or grant permission to send messages.
