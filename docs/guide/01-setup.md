# Set up Hapstack

Install the full package using the root README's provider-specific skills CLI command or a compatible Agent Plugins client. Do not overwrite existing customized skills without choosing which source owns them. Use one installation scope and reload through the host's supported mechanism.

Invoke setup-hapstack. It detects host capabilities and actual available model IDs/options, offers reasoning budgets and role panels, and configures delegation, tooling, versioning, and optional changelog policy. It stores preferences outside the installed package; global settings never belong in public source. Project settings take precedence.

No configuration is required to start: current-model roles, on-request delegation, existing tooling, and project-defined shipping are defaults. No particular provider is required. Configuration does not change the current chat's composer selection, migrate tools, or activate schedules.

See [setup](../../skills/setup-hapstack/SKILL.md), [configuration](../../skills/setup-hapstack/references/configuration.md), and [the runtime contract](../../skills/hap-mode/references/runtime.md).
