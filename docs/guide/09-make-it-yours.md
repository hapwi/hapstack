# Customize your workflow

Use [automate-me](../../skills/automate-me/SKILL.md) to draft or revise a personal mode from explicit preferences and authorized history. Do not read unrelated projects' conversations. If history is unavailable, use the visible conversation and a clearly labeled digest.

Customize model roles, effort, delegation, tooling, and versioning through [setup-hapstack](../../skills/setup-hapstack/SKILL.md). Keep those preferences outside installed files so package updates do not overwrite them. Do not put credentials or private paths into a shared configuration.

A mode can route to selected installed skills, including patcher and ship, without copying one operator's home paths or mandatory tool preferences. Use supported skill-authoring guidance, valid metadata, discoverable relative references, and proportionate checks. Update the package deliberately rather than replace local user changes during an upstream sync.
